# Hybrid-Graph-Learning-for-Muti-feature-Missing-Data-Imputaion
This repository presents a hybrid architecture combining a learnable Temporal Decay-Gap Mechanism and Mask-Aware Fusion attention for muti-feature missing data imputaion.

# Datasets
The PEMS-BAY, METR-LA, and Seattle datasets and their adjacency matrices, along with the case study dataset, are publicly available at  https://drive.google.com/drive/folders/1WnM4D6fiyhbrJg0IiPQi2Vqo1dFwZyTM?usp=sharing.

# Usage
To train and evaluate the model, from the terminal run 
```bash 
python3 main.py
```
